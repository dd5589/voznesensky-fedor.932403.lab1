# Лабораторная работа: «О себе»

**Вариант 11**  
**Тема:** Фотограф и визуальный сторителлер

## Описание
Одностраничный сайт-визитка фотографа. Страница содержит информацию об авторе, его навыках, проектах и форму обратной связи. Дизайн выполнен в серо-синей цветовой гамме.

## Структура страницы

- **Шапка (`<header>`)**  
  Имя и фамилия (`<h1>`), заголовок страницы (`<h2>`), аватар (одно изображение с атрибутами `src`, `alt`, `width`, `height`).

- **Основной контент (`<main>`)**
  - Секция **«Навыки»** – маркированный список (`<ul>`) с фотографическими навыками.
  - Секция **«Проекты»** – нумерованный список (`<ol>`) из четырёх фотопроектов.
  - **Форма обратной связи** – поля «Имя» (`type="text"`), «Email» (`type="email"`), «Сообщение» (`<textarea>`) и кнопка отправки. У всех полей указаны атрибуты `name` и `placeholder`.

- **Боковая панель (`<aside>`)**  
  Указано любимое направление в фотографии – пейзажная фотография.

- **Подвал (`<footer>`)**  
  Копирайт с именем автора и годом.

## Запуск
Откройте файл `index.html` в любом браузере.
