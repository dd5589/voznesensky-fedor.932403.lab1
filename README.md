# Лабораторная работа №1. Основы HTML и структура веб-страницы 

**Вариант 11**  
**Тема:** Фотограф и визуальный сторителлер

## Описание
Одностраничный сайт-визитка, содержащий информацию о фотографе и его проектах.  
Описание страницы:

- Шапку с именем и аватаром
- Две секции: «Навыки» (маркированный список) и «Проекты» (нумерованный список из 4 пунктов)
- Боковую панель с любимым направлением в фотографии
- Форму обратной связи (имя, email, сообщение)
- Подвал с копирайтом и годом

## Используемые технологии
- HTML5

## Структура проекта
- `index.html` – основной файл
- `avatar.jpg` – изображение (аватар)
- `README.md` – описание проекта

## Запуск
Откройте файл `index.html` с помощью браузера.
